1 · Scope and conventions

Given specs vs design outcomes

Two kinds of numbers get mixed up in LDO reviews. Givens come from the system and do not move with topology or silicon: supply range, load range, temperature range, lifetime, and the output capacitor with its ESR window. Design outcomes are what the review actually signs off: dropout, stability, transient, PSRR, accuracy, Iq and the rest. Every check below measures an outcome against a limit, swept across the givens.

5 · SKILL script: add the load regulation test
  1. Edit sections 1 to 3 of the script: library, testbench cell, setup view, and the four net names.
  2. Close the setup in the GUI, or open it read-only, so the script can open it for editing.
  3. Paste into the CIW, or save as ldo_loadreg_setup.il and run load("ldo_loadreg_setup.il").
  4. Reopen the setup. The new test LDO_LoadReg runs against your existing corners, with pass/fail against the two specs.
Built on the ADE Assembler mae* SKILL API (IC6.1.8 and newer). It has not been run on your install. The script prints the DC analysis settings after it sets them; if the sweep is empty, set the iload sweep once by hand and the outputs and specs still apply. Classic ADE XL on IC6.1.7 uses the older axl* API instead.
ldo_loadreg_setup.il
;; ====================================================================
;; ldo_loadreg_setup.il
;; Adds an LDO load-regulation test to an existing ADE XL / ADE Assembler
;; (maestro) setup whose testbench schematic already has the LDO hooked up.
;;
;; How to use
;;   1. Edit the values in sections 1 to 3 below.
;;   2. Close the setup view in the GUI (or open it read-only) so this
;;      script can open it for editing.
;;   3. In the CIW:   load("ldo_loadreg_setup.il")
;;
;; Testbench assumptions
;;   - A DC current sink from DUT_OUTPUT to ground, value = ILOAD_VAR
;;   - A DC voltage source on DUT_POWER, value = VIN_VAR
;;   - Output cap and ESR already on the schematic
;;
;; Needs the mae* SKILL API: IC6.1.8 with ADE Assembler, or IC23 / IC25.
;; Not tested on your install; check the printed DC analysis settings.
;; ====================================================================
let((
    ;; ---------- 1. Where the setup lives ----------
    (LIB        "myLib")        ; library holding the adexl / maestro view
    (CELL       "tb_ldo")       ; testbench cell
    (VIEW       "adexl")        ; "adexl" or "maestro"
    (TB_VIEW    "schematic")    ; testbench schematic view
    (TEST       "LDO_LoadReg")  ; name of the test this script adds

    ;; ---------- 2. Net and instance names ----------
    (DUT        "I0")           ; $DUT        LDO instance in the testbench
    (DUT_POWER  "VIN")          ; $DUT_POWER  net on the LDO input pin
    (DUT_GND    "GND")          ; $DUT_GND    net on the LDO ground pin
    (DUT_OUTPUT "VOUT")         ; $DUT_OUTPUT net on the LDO output pin
    (ILOAD_VAR  "iload")        ; design variable on the DC load sink
    (VIN_VAR    "vin")          ; design variable on the VIN source

    ;; ---------- 3. Operating point and spec limits ----------
    (VIN_VAL      "1.8")
    (VOUT_NOM     "1.2")
    (ILOAD_MIN    "1m")
    (ILOAD_MAX    "300m")
    (NPTS         "31")
    (SPEC_LOADREG "20")         ; load regulation, mV/A, max
    (SPEC_ERR     "1.5")        ; VOUT error over load, %, max
    (RUN          t)            ; t = set up and run, nil = set up only

    sess vs vp dcOpts outs hist ok)

  ;; ---------- open the setup ----------
  sess = maeOpenSetup(LIB CELL VIEW ?mode "a")
  unless(sess
    error("ldo_loadreg: cannot open %s/%s/%s for editing. Close it in the GUI and retry.\n"
          LIB CELL VIEW))
  when(member(TEST maeGetSetup(?session sess))
    error("ldo_loadreg: test %s already exists. Change TEST or delete that test first.\n" TEST))

  ;; ---------- test and design variables ----------
  maeCreateTest(TEST ?lib LIB ?cell CELL ?view TB_VIEW ?simulator "spectre" ?session sess)
  maeSetVar(VIN_VAR    VIN_VAL   ?session sess)
  maeSetVar("VOUT_NOM" VOUT_NOM  ?session sess)
  maeSetVar(ILOAD_VAR  ILOAD_MIN ?session sess)

  ;; ---------- DC sweep of the load current ----------
  dcOpts = `(("saveOppoint" t) ("param" ,ILOAD_VAR)
             ("start" ,ILOAD_MIN) ("stop" ,ILOAD_MAX) ("lin" ,NPTS))
  ;; argument order changed between releases, so try both forms
  ok = errset(maeSetAnalysis(TEST "dc" ?enable t ?options dcOpts ?session sess))
  unless(ok && car(ok)
    ok = errset(maeSetAnalysis("dc" ?enable t ?options dcOpts ?session sess)))
  unless(ok && car(ok)
    printf("ldo_loadreg: could not set the DC sweep. Set it by hand: sweep %s from %s to %s.\n"
           ILOAD_VAR ILOAD_MIN ILOAD_MAX))
  printf("ldo_loadreg: DC analysis now reads %L\n"
         car(errset(maeGetAnalysis(TEST "dc" ?session sess))))

  ;; ---------- outputs and specs ----------
  vs = sprintf(nil "VS(\"/%s\")" DUT_OUTPUT)
  vp = sprintf(nil "VS(\"/%s\")" DUT_POWER)
  outs = list(
    list("VOUT"              vs nil nil)
    list("VOUT_light"        sprintf(nil "value(%s %s)" vs ILOAD_MIN) nil nil)
    list("VOUT_heavy"        sprintf(nil "value(%s %s)" vs ILOAD_MAX) nil nil)
    list("load_reg_mV_per_A" sprintf(nil "1000*(value(%s %s) - value(%s %s))/(%s - %s)"
                                     vs ILOAD_MIN vs ILOAD_MAX ILOAD_MAX ILOAD_MIN)
                             "lt" SPEC_LOADREG)
    list("VOUT_err_pct"      sprintf(nil "100*ymax(abs(%s - VOUT_NOM))/VOUT_NOM" vs)
                             "lt" SPEC_ERR)
    list("headroom_V"        sprintf(nil "value(%s - %s %s)" vp vs ILOAD_MAX) nil nil))
  foreach(o outs
    maeAddOutput(nth(0 o) TEST ?expr nth(1 o) ?session sess)
    when(nth(2 o)
      maeSetSpec(nth(0 o) TEST ?lt nth(3 o) ?session sess)))

  ;; ---------- save, then optionally run ----------
  maeSaveSetup(?lib LIB ?cell CELL ?view VIEW ?session sess)
  printf("ldo_loadreg: test %s saved in %s/%s/%s (DUT %s, GND net %s).\n"
         TEST LIB CELL VIEW DUT DUT_GND)
  when(RUN
    hist = maeRunSimulation(?session sess)
    maeWaitUntilDone('All)
    printf("ldo_loadreg: run finished, history %L. Open the view to see pass/fail per corner.\n" hist)
    errset(maeExportOutputView(?session sess
                               ?fileName strcat("./" TEST "_results.csv")
                               ?view "Detail")))
  sess)
6 · Reference, public online data
  1. P. Hazucha et al., "Area-efficient linear regulator with ultra-fast load regulation," IEEE JSSC, vol. 40, no. 4, 2005
    Source of the response-time figure of merit (Hazucha FOM).
  2. TI SSZTA58, LDO Basics: Current Limit
    Brick-wall vs foldback current limit.
  3. TI TLV717P datasheet
    Real foldback curve, 350 mA onset and 40 mA short-circuit current.
  4. TI SBVA097, LDO Current Limit Behavior During Dropout Operation
    Hybrid brick-wall and foldback scheme.
  5. TI E2E, TPS746-Q1 foldback current limit
    Current limit measured at 85% of VOUT nominal.
  6. TI SSZTAD7, LDO Basics: Power Supply Rejection Ratio
    PSRR versus frequency, headroom and COUT.
  7. TI SLAA414, LDO PSRR Measurement Simplified
    Measurement methods for the PSRR check.
  8. TI SLYT202, Analog Applications Journal, PSRR in LDO applications
    Why PSRR drops at heavy load and near dropout.
  9. TI SLAA412, LDO Noise Demystified
    Noise density vs integrated noise, and why bandwidth belongs in the spec.
  10. TI SLYT201, Understanding noise in linear regulators
    Output-referred noise and its main sources.
  11. TI SSZT658, LDO Basics: Preventing Reverse Current
    Body-diode path and blocking methods for the reverse current check.
  12. TI SBVA026, A Topical Index of TI LDO Application Notes
    Index to the rest of the TI LDO app notes.
  13. TI SLVA289B, Feedforward capacitor for internally compensated converters
    Feedback divider and feed-forward zero, from this project's earlier page.
  14. P. E. Allen, CMOS Analog Circuit Design, Lecture 23: Two-Stage Op Amps
    Miller compensation values used for the error-amp model.
  15. Cadence Community, maestro SKILL: maeCreateTest and maeSetAnalysis
    Working example of the calls the script uses.
  16. Cadence Community, building maeAddOutput expressions from variables
    Why the script builds each expression with sprintf.
